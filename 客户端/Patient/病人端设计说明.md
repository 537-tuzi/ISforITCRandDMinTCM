# 病人端（Patient）界面与交互设计说明

> 依据：`客户端/病人端原型.html`（唯一视觉与交互基准）、项目手册 3.3 节及表 3、工信部《移动互联网应用（APP）适老化通用设计规范》。
> 窗口规格（2026-10-30 决定，覆盖原 1280×860）：登录窗口贴内容（卡片即窗口，无空白）；主窗口与其余界面一律 800×640；字号取"容器内不溢出、不裁切"前提下的最大值（§1.2 字号表为理想值，按 800×640 等比折算）。
> 首页简化（2026-10-30 决定）：四宫格去掉标题前图标块；待办卡去「未过期的预约」角注；待办行改为——第一行 科室·医生+状态胶囊，第二行 日期+起止时间+取消（去掉星期/今天/晚班等前缀词）；退出登录按钮改红底白字。§4 相应描述以本条为准。
> 本文档是 Qt 客户端（客户端/Patient 工程）的实现规格；文中所有文案均为**逐字标准**，实现时不得改写。

## 1. 全局设计规范

### 1.1 配色（4 色制）
| 用途 | 色值 |
|---|---|
| 页面底 | `#fafaf7` 暖白 |
| 卡面 | `#ffffff` 纯白，边框 `#e5e3da` |
| 主色（导航条/主按钮/激活态/链接） | 墨绿 `#2e5e50`，按压 `#234b40` |
| 警示（取消/错误/重症） | 朱砂 `#b23b2e`，浅底 `#fbeeea` |
| 文字 | 墨黑 `#262620`，次要 `#5f5f56`，辅助 `#74746a` |
| 主色浅底（图标块/气泡/成功提示） | `#e7f0ea` |

### 1.2 字号（下限 15px，正文 ≥17px）
- 顶部导航 24px（按钮高 58px）；用户徽章 18px
- 卡片标题 22px，角注 15.5px
- 首页宫格：标题 42px（楷体加粗）、描述 23px、图标块 90px
- 按钮文字：主 19px（高 56px）、大按钮 21px（高 64px）、小按钮 16.5px（高 48px）
- 表格 17px / 表头 15.5px；明细行 18px；弹窗正文 18px；toast 19px

### 1.3 状态胶囊（圆点+文字双通道）
| 样式 | 文案 | 使用处 |
|---|---|---|
| 绿底绿点 | 已建档 / 已预约 | 建档状态、待办、记录表 |
| 灰底灰点 | 未建档 / 已取消 / 已问诊 | 同上 |
| 白底红描边红点 | 即将就诊 | 距就诊不足 30 分钟的预约 |

### 1.4 通用组件
- **toast**：顶部居中悬浮，深底白字 19px，3.2 秒自动消失；警示类红底。
- **弹窗**：右上角关闭按钮（≥36×36），底部按钮靠右。
- **退出登录**：红描边大按钮，位于左侧个人信息面板底部（首页/检测/记录三页均有；建档页无）。

## 2. 窗口与导航结构

```
登录窗口 ──登录成功──> 主窗口
主窗口 = 顶部导航条（墨绿）+ 内容区
  导航：首页 │ 初次建档(建档后：我的档案) │ 舌苔检测 │ 就诊记录 …… [用户徽章: ●李 李建国]
导航守卫：未完成建档时，点击"舌苔检测"或"就诊记录"→ toast「请先完成初次建档业务」，不切换。
```

## 3. 登录窗口

### 3.1 静态内容
| 元素 | 内容 |
|---|---|
| 标题 | 中医舌苔智能识别系统（楷体 29px，居中） |
| Tab1（默认激活） | 医保账号登录 |
| Tab2 | 手机验证码登录 |
| 医保账号输入框 | 占位符「请输入医保卡号」 |
| 医保密码输入框 | 密码型，占位符「请输入密码」，下方小字「演示密码：123456」 |
| 手机号输入框 | 占位符「请输入注册手机号」 |
| 验证码输入框 | 占位符「请输入验证码」+「获取验证码」按钮 + 「念给我听」按钮（tooltip：看不清？念给您听）；下方小字「演示验证码：123456」 |
| 登录按钮 | 「登 录」（大按钮） |
| 底部说明 | 密码连错 3 次将临时锁定医保登录 15 分钟<br>没建过档的用户，登录后会自动引导到「初次建档」 |

### 3.2 交互规则
1. **医保登录**：密码为空 → toast「请输入医保密码」。密码错误 → 计数；第 1、2 次 toast「医保密码错误，请重新输入（还剩 X 次机会）」（X=剩余次数）；**第 3 次**：toast「医保登录已临时锁定，请 5 分钟后再尝试登录」，并**清空医保账号、密码两个输入框**，计数归零。（提示语照抄手册原文；手册正文"锁 15 分钟"与提示语"5 分钟"自相矛盾，以原文提示语为准，答辩时说明）
2. **验证码登录**：手机号为空 → toast「请输入手机号」；验证码 ≠123456 → toast「验证码不对（演示：123456）」。
3. **获取验证码**：点击后按钮禁用，文字变「重新获取(60s)」逐秒递减，归零恢复「获取验证码」；同时 toast「验证码已发送，请查收短信（演示：123456）」并语音播报「验证码已发送，请查收短信」。
4. **念给我听**：语音播报「您的验证码是 1 2 3 4 5 6」。
5. **登录成功**：进入主窗口；若未建档 → toast「该医保账号未建立档案，请先进入初次建档」并直接切到初次建档页；否则进首页。

### 5.2 AI 语音助手面板（标题：AI 语音助手，角标「在线」绿点闪烁）
- 首条固定播报（进入页面即显示）：
  > 您好！我是您的健康助手，帮您完成建档。您的姓名、年龄等基本信息已从医保账号自动带入，左侧带锁的项不用填。接下来我问您几个问题，帮您把「过敏史」「既往病史」录进去：按住下面的按钮说话，说完松手就行。
- 底部按钮：【🎤 按住说话（说完松手）】——按下采集、松开结束，可点击多次。
- 每次松开：先追加用户气泡「（您说）…」，0.5 秒后追加 AI 回复气泡，并自动把识别结果填入左侧对应输入框。
- 演示对话脚本（共 4 轮，走完为止）：

| 轮 | 用户说 | AI 回复（0.5 秒后显示） | 自动填充 |
|---|---|---|---|
| 1 | 我对青霉素过敏。 | 好的，您的姓名、年龄等基本信息已经从医保账号带入了。请问您有药物或食物过敏吗？ | 过敏史=青霉素 |
| 2 | 我有高血压五年了，一直吃降压药。 | 已记下「青霉素过敏」。请问您以前生过什么病、或长期吃什么药吗？ | 既往病史=高血压 5 年（服降压药） |
| 3 | 睡眠一般，不吸烟，偶尔喝一点酒。 | 收到。您平时睡得好吗？抽烟喝酒吗？ | 既往病史=高血压 5 年（服降压药），睡眠一般 |
| 4 | （无语音，仅结束语） | 信息都录好了！左边「过敏史」「既往病史」可以自己再改。都确认好了就点「保存并上传」。 | — |

执行顺序：用户每松开一次按钮，先显示用户气泡，0.5 秒后显示该轮 AI 回复并填充左侧输入框；4 轮走完后再按不再有新对话。

- **保存校验**：过敏史为空 → toast「「过敏史」还没有填，没有就填「无」」；既往病史为空 → toast「「既往病史」还没有填，没有就填「无」」。
- **保存成功**：jdDone=true；格①/导航切「我的档案」；若从未进行语音对话（aiIdx==0），AI 首条播报替换为「您的健康档案已建立。左侧「过敏史」「既往病史」可随时修改，或按住下方按钮语音更新，改完点「保存并上传」。」；各页面板过敏史/既往史/建档状态同步；toast「档案已保存上传，正在返回首页…」；1.2 秒后自动切回首页。

### 6.2 中间摄像头卡

- 画面区（深底 300px，四角取景框）：中央舌头水印 + 文字「摄像头实时画面」；检测中显示绿色扫描线动画。
- 【开始检测】大按钮：点击后禁用、文字变「正在检测，请保持不动…」，1.8 秒后出结果并恢复。
- 结果三格（值 24px）：舌苔类型 / 健康状态 / 置信度；默认「—」，检测中「识别中 / … / …」。

### 6.3 右侧报告列
- **检测报告**卡：标题右侧显示 `检测日期 · 耗时 ms`（如 `2026/10/29 · 137 ms`）；正文为结果条目列表；重症时整卡红边并追加红色提示「结果较重，系统已自动挂号，请查看弹窗确认。」；默认文案「还没有检测结果，请点击「开始检测」。」
- **养生建议**卡：默认「检测完成后，这里会根据您的舌头情况给出饮食、作息、调理建议。」；出结果后显示对应养生文案（重症整卡红边）。

### 6.4 底部三按钮
【保存报告】→ toast「报告已保存到服务器，与您的档案绑定」；【再检测一次】→ 清空结果并循环到下一类演示结果，toast「已重置，本次将模拟「X」结果」；【预约医生】→ 打开手动预约弹窗。

| 类型 | 健康状态 | 置信度 | 严重度 | 自动预约 | 报告条目 | 养生建议全文 |
|---|---|---|---|---|---|---|
