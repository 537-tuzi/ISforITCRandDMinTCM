# 医生端与管理员端拆分设计说明

> 依据：项目手册表5/表6 + 3.4/3.5 详设；《手册符合性对照表.md》已裁决口径；三视角发散设计（手册忠实+医疗场景/适老化+工程架构）交叉评审终稿。
> 用户决定（2026-10-31）：将合并工程"客户端/Staff"拆为**两个独立可执行程序**，登录不同账号进入各自界面。
> 本文档是两端 Qt 工程的实现规格（原型框架，不含真实网络逻辑）；所有界面文案为逐字标准，实现时不得改写。

## 二、共享层 `客户端/_shared/`

```
_shared/
├── staff_common.pri          # 首行 COMMON=$$PWD；INCLUDEPATH+=$$COMMON（util/view 子目录层级保留，
│                             #   现 Staff 12 个 View 迁入时 #include 路径零改动）
├── shared.qrc                # style_base.qss
├── style_base.qss            # Patient 四色制与控件基类（#card/#btnPri/#btnOut/#tb/#pill*/#toast/#modal）
│                             #   各端 style.qss 只写覆盖层并入各自 qrc
├── util/
│   ├── Toast / UiScale（基准 1280）/ UIFactory
│   ├── AppDefs.h             # 三端公共子集 + shiftName 班次文案 + 演示账号表
│   ├── PageBar               # 手册 5 处翻页+首末页**弹窗**警告单点实现
│   ├── ExcelExporter         # libxlsxwriter 真 .xlsx 优先（EXISTS() 探测），缺失回退 CSV+UTF-8 BOM
│   └── Proto.h               # 纯 C++11 无 Qt：MsgType 枚举+JSON 字段名+舌象类别码 0-4/0xFF
│                             #   （衔接全链路类别顺序强一致规则，未来服务端直接复制同文件）
├── view/
│   ├── StaffLoginView        # 参数化共享登录窗（端名+期望角色）
│   └── StaffProfileView      # 参数化共享改密窗（四项表单）
└── StaffTypes.h              # namespace sst 共用子集：Role/SchedCell/LeaveRow/shiftName/演示账号表
```

**类型拆分**：`drt`（Doctor/util/DoctorTypes.h）= PatientRow/TongueReport/RxItem/VisitCase；`adt`（Admin/util/AdminTypes.h）= DoctorRow/DeptRow/LogRow/StatRow；Page 枚举按端拆 DoctorPage/AdminPage。

**演示数据仓**（排班/账号/日志）放 `_shared` 同源——管理员排班保存→医生端立即可见的同步闭环天然成立。

## 五、代码复用选型

**`.pri` 源码共享**（不建静态库、不同构复制）。理由：共享量约 1500-2000 行，两 exe 各自重编耗时秒级；staticlib 的 subdirs 构建序+moc 并入+跨库调试全为负收益；同构复制在 3-4 份同名文件时必然漂移。qmake 官方多工程做法即 subdirs+include(.pri)。

可选建 `客户端/Clients.pro`（TEMPLATE=subdirs，SUBDIRS += Patient Doctor Admin）做一把梭构建。

**Patient 冻结不动**（已验收适老范式，不并入 _shared）；Patient 的 util 同源漂移留待下次触碰时收口。

## 六、迁移路线

1. 建 `_shared`，自 Staff 上收 util 五件套+StaffTypes+登录/改密 View → 两 exe 编译通过
2. Staff 的 5 个医生页→Doctor、5 个管理员页→Admin（`sdt`→`drt`/`adt` 机械替换）；MainWindow 两端描述表驱动重写左侧栏版
3. 两 exe 编译通过后 `客户端/Staff` 整目录 git rm（**拆替不并存**）
4. 新建 `_shared/`、`Doctor/`、`Admin/` 三目录在 `docs/文件分类整理规则.md` 登记表登记并同步 .gitignore 与 README
