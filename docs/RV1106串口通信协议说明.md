## 一、串口下行控制（PC → RV1106）

### 1.1 4 字节固定帧结构定义

| 字节序号 | 字段 | 说明 |
| --- | --- | --- |
| 1 | 帧头 `0x5A` | 固定起始标识 |
| 2 | CMD_H | 指令高 8 位 |
| 3 | CMD_L | 指令低 8 位 |
| 4 | 帧尾 `0xA5` | 固定结束标识 |

### 1.2 核心控制指令映射表

| 指令码 (CMD) | 功能描述 | 设备运行模式 |
| --- | --- | --- |
| 0x0000 | 停止所有视频流输出 | MODE_STOP_VIDEO |
| 0x0001 | 仅播放视频，不进行推理 | MODE_PLAY_VIDEO |
| 0x0010 | 抓拍单帧图像并执行推理 | MODE_SINGLE_INFER |
| 0x0100 | 持续采集视频并实时推理 | MODE_CONTINUE_INFER |

### 1.3 指令发送示例

若需触发「单帧拍照推理」功能，需下发指令 **0x0010**。
实际串口下发的 4 字节帧为：

```
0x5A 0x00 0x10 0xA5
```

即：帧头 + 指令高 8 位 + 指令低 8 位 + 帧尾。

## 二、串口上行响应（RV1106 → PC）

### 2.1 6 字节固定帧结构详解

| 字节序号 | 字段 | 说明 |
| --- | --- | --- |
| 01 | 帧头 `0x5B` | 上行数据起始标识，与下行 0x5A 区分，防止混淆 |
| 02 | 指令高 8 位 | 回显下行控制指令的高 8 位，用于校验指令对应关系 |
| 03 | 指令低 8 位 | 回显下行控制指令的低 8 位，确保指令完整性校验 |
| 04 | 分类结果 | AI 模型推理的舌苔分类编码，具体映射见下方表格 |
| 05 | 置信度 | 0x00~0x64（即 0%~100%），数值越高结果越可信 |
| 06 | 帧尾 `0xA5` | 固定结束标识，用于确认数据帧传输完整无误 |

### 2.2 舌苔分类编码映射表

| 编码 (HEX) | 舌苔类型名称 | 说明 |
| --- | --- | --- |
| 0x00 | 灰黑苔 | 常见病理舌苔类型 |
| 0x01 | 镜面舌 | 舌面光滑如镜，无舌苔 |
| 0x02 | 薄白苔 | 正常或表证初期常见 |
| 0x03 | 白腻苔 | 常见病理舌苔类型 |
| 0x04 | 黄腻苔 | 常见病理舌苔类型 |
| 0xFF | 未识别 / 异常 | 检测失败或无有效目标 |

### 2.3 上行指令回传示例

当 RV1106 完成单帧图像推理后，主动向上位机回传 6 字节结果帧。

示例帧：

```
5B 00 10 02 5C A5
```

包含：帧头 + 指令回显 + 分类结果 + 置信度 + 帧尾，结构紧凑。

**示例帧含义逐字节解读**（依据指令映射表与分类映射表推导）：

- `5B`：上行帧头
- `00 10`：回显下行指令 0x0010（单帧拍照推理）
- `02`：分类结果为薄白苔（对应 2.2 表中 0x02）
- `5C`：置信度为 0x5C，即 92/100 = 92%
- `A5`：帧尾

## 三、注意事项（图右下角备注）

1. **帧头区分通信方向**：上行帧头 `0x5B` 与下行帧头 `0x5A` 严格区分通信方向，防止混淆。
2. **串口参数一致性**：所有串口通信参数需与模组端配置保持一致（波特率 115200、数据位 8、停止位 1、无校验位），以保证数据传输稳定性。
