# 中医舌苔智能识别与诊疗管理一体化系统

基于凌智 RV1106 边缘摄像头实现舌苔本地实时识别推理，结合 Ubuntu22.04 环境下 C++ 内核级服务端、多角色 Qt 客户端，打造集**舌苔智能检测、AI 语音交互、自动预约挂号、医生诊疗、病例管理、后台运维**于一体的一体化系统，适配中小型中医馆、社区中医服务站的实际应用场景。

## 系统架构

```
┌─────────────────┐   串口/网络   ┌──────────────────────┐   TCP   ┌────────────────────────┐
│  采集端 RV1106   │ ───────────→ │  服务端 (Ubuntu C++)  │ ──────→ │  Qt 客户端三角色         │
│  舌苔图像采集     │              │  epoll + 线程池       │         │  病人端 / 医生端 / 管理员端│
│  YOLOv8 本地推理 │ ←─────────── │  MySQL 8.0 持久化     │ ←────── │  (Qt Creator 跨平台)     │
└─────────────────┘   指令下发    └──────────────────────┘   JSON  └────────────────────────┘
```

- **采集端**：RV1106 本地完成舌苔采集与 YOLOv8 推理（识别准确率≥95%、单帧耗时≤200ms、无网络依赖），结果通过串口按协议上报
- **服务端**：epoll IO 复用 + 线程池，支持 ≥500 路终端并发接入；MySQL 8.0 持久化，读写响应≤50ms，支持每日定时备份
- **三角色客户端**：病人（AI 语音建档、舌苔检测、自动/手动预约）、医生（问诊、开方、病例）、管理员（排班、统计、档案管理），角色权限严格隔离

## 快速开始（模型部分）

```bash
# 1. 训练
python training/train.py

# 2. 导出 ONNX 并转 RKNN（校准量化）
yolo export model=best.pt format=onnx
python convert.py best.onnx rv1106 i8 tongue.rknn

# 3. 板端运行（RV1106，串口按协议与上位机通信）
./yolov8_main tongue.rknn 5 tongue_list.txt
```

## 串口通信协议（摘要）

- 下行（PC → RV1106）：`0x5A | CMD_H | CMD_L | 0xA5`，指令含停止视频/仅播放/单帧推理/连续推理
- 上行（RV1106 → PC）：`0x5B | CMD_H | CMD_L | 类别码 | 置信度 | 0xA5`，类别码 0x00~0x04 对应灰黑苔/镜面舌/薄白苔/白腻苔/黄腻苔，0xFF 表示异常
- 串口参数：115200 8N1；详见 `docs/RV1106串口通信协议说明.md`

## 数据库

`docs/zysms_db.sql` 一键建库 `zysms_db`（utf8mb4），含患者、工作人员、科室、排班、舌苔检测记录、预约、诊疗记录、处方、系统配置、系统日志共 10 张表，附联调测试数据（默认密码 123456 的 MD5）。
